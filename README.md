
# Junior Web Programming - Modul 1

## Instalasi Software Tools Pemrograman

Repository ini merupakan dokumentasi pengerjaan Modul 1 pada pelatihan Junior Web Programming.

## 1. Software dan Tools yang Digunakan

| No. | Tools | Kegunaan |
|-----|-------|----------|
| 1 | Visual Studio Code | Editor untuk menulis dan mengelola kode program |
| 2 | Google Chrome | Browser untuk menjalankan dan menguji halaman web |
| 3 | Git | Version control untuk mengelola perubahan kode |
| 4 | GitHub | Platform penyimpanan repository proyek |
| 5 | Live Server | Menjalankan halaman web secara lokal |
| 6 | Prettier - Code formatter | Memformat kode agar lebih rapi dan konsisten |
| 7 | ESLint | Membantu mendeteksi masalah pada kode JavaScript |
